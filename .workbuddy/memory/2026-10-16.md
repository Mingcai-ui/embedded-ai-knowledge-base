- 分组：P0 必买 / W25Q64(P2) / 上行模组(P3) / 配件耗材 / 可选项，共 20 项，合计约 ¥420–680。
- **关键选型结论（重要，勿忘）**：RS485 收发模块**必须能手动控制 DE/RE**，市面上"自动收发"成品模块（RC+三极管自动切方向）会把方向引脚吞掉，导致核心一考点"方向切换时序（发送完成中断后再切、早/晚一个 bit 的后果）"练不到。→ 首选 MAX485 裸芯片 DIP-8（立创 C32710645 / 34444164），自己接 DE/RE。
- 其他选型红线：STM32F103 为 3.3V、MAX485 为 5V（IO 5V 容忍可用，全 3.3V 则用 SP3485/MAX3485）；W25Q64 是 3.3V；ESP-01S 峰值 170mA 需独立 3.3V 稳压，推荐直接用 ESP32-DevKitC 省坑。
