# 进度 · 2026-11-10 · Modbus 传感器节点方向确认

## 本次确认了什么

1. **纠正一个方法论错误**：原想法"每个传感器自行封装成 Modbus 帧"是歪路。正确姿势是**传感器只填寄存器，帧由通用从站协议栈统一组**——可移植性来自「固定寄存器地图 + 传感器登记表（sensor_map）」，不是更多组包函数。现有 `makePacket_03` 已通用，零改动。
2. **给传感器节点定位**：0x02 多传感器节点（DHT11 + MPU6050）既是核心一验收需要的"从机模拟器"测试资产，也是市场故事载体——定位"机柜/机房环境 + 设备状态监测节点"（温湿度 + 振动/倾角）。应用层只做轻量工程量换算，不做 FFT/OTA/组态。
3. **重心拉回主交付物**：主线是网关主站协议栈（核心一），近两周代码全在桥/从站侧属重心偏移。从站收口后必须回主站 P0。
4. **行动顺序**（12 月广西赛为硬截止）：① 收口 0x02 节点（sensor_map + 填槽 + Modbus Poll 端到端实测）→ ② 主站上板轮询 0x01+0x02，闭环 P0 → ③ P1 零丢帧 + 3 从机 + 超时预算，FreeRTOS 只上网关，节点永久裸机。
5. **护栏**：不写每传感器一个组包函数；不推进"主站读到从站真实数据"的功能先不做；OLED 只当调试屏；主站协议栈按档卡纪律手写。
