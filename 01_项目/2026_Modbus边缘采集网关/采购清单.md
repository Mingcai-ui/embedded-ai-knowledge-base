# Modbus 边缘采集网关 · 采购清单（BOM）

> 主档卡：[[Modbus边缘采集网关-主档卡]]。本清单按「先能开工 → 再上可靠性 → 最后上云」的 P0–P3 顺序分组，并附选型注意。
> 价格为主流电商参考价（2026-10 查询），随库存/活动波动，下单前请复核。

## 0. 选型红线（先看这条）

1. **RS485 收发模块必须能手动控制 DE/RE**。核心一的"方向切换时序"是面试白板题（"早/晚一个 bit 会发生什么"），自动收发的成品模块会把这个引脚吞掉，等于主动放弃一个考点。→ 首选带 DE/RE 的模块，或直接买 MAX485 裸芯片自己搭。
2. **电平要对齐**：STM32F103 是 3.3V 逻辑；MAX485 是 5V 器件（STM32 IO 5V 容忍，可用），若想全 3.3V 则用 SP3485 / MAX3485。
3. **W25Q64 是 3.3V**，别接 5V。
4. **ESP-01S 峰值电流 170mA**，STM32 板载 LDO 常带不动，需独立 3.3V 稳压，否则一发数据就复位。

## 7. 下单优先级（按项目阶段）

1. **本周**：MAX485 芯片 ×5 + USB转RS485 ×2 + 杜邦线/面包板/12V 电源 → 能开始 P0
2. **P0 打通后**：温湿度表 ×2 + 导轨电表 → 能开始 P1 多从机轮询
3. **进 P2 前**：W25Q64 模块 ×2 + 去耦电容
4. **P3 前拍板**：ESP32（优先）或 4G 模组
