## 一句话总结
STM32Cube HAL/LL 驱动库的权威说明文档：讲清 HAL（硬件抽象层）与 LL（底层驱动）两套 API 的架构、命名规则、数据结构和各外设驱动用法。

## 关键要点
- **HAL**：面向功能、高层、可移植性高的 API，特性式封装（如把定时器拆成互相独立的 API），隐藏寄存器细节。
- **LL（Low-layer）**：面向寄存器、低层 API，更贴近硬件，性能更高；仅部分外设提供 LL API。
- 二者互补：HAL 求通用/可移植，LL 求精简/高性能。
- 驱动一律用严格 ANSI-C 编写，和编译器无关。
- 章节导航：
  - 2 章：HAL 驱动总览、HAL 数据结构和 "HAL/user 应用文件" 组织
  - 2.5 节：**HAL API 命名规则**（`HAL_` + 外设 + 操作）、中断处理与回调函数约定
  - 2.6/2.7：HAL 通用 API 与扩展 API
  - 后续章节：各外设（GPIO/UART/SPI/I2C/TIM/ADC…）HAL 与 LL 驱动的逐模块说明
