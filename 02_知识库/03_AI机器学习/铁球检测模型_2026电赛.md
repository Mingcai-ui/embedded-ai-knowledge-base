# 铁球检测模型（2026 电赛 · YOLOv5）

## 简介

2026 年电子设计竞赛期间，用 **YOLOv5** 训练的目标检测模型，用于**识别小铁球**。模型已用 nncase 编译为 K230 可加载的 **kmodel** 格式（魔数 `LDMK`），可直接部署到 CanMV/MicroPython 的 KPU 上做边缘推理。

> ⚠️ 这是**单类目标检测**（检测框定位铁球），与知识库里已有的「扑克牌 54 类**图像分类**」是完全不同的任务类型：检测输出的是**框坐标 + 置信度**，分类输出的是**类别 softmax**。

## 训练与数据说明

- **数据集**：多小球数据集训练，针对真实场景做了**数据增强**：
  - 干扰物遮挡增强
  - 运动模糊增强
- **已知表现**：识别效果较好。
- **类别**：单类，类别名 `qiu`（铁球）。
- **已知风险**：可能受**灯光影响**——数据集中小球带有**灯光高光点**，强光/反射环境下置信度可能波动，落地时需注意光照稳定性。当出现识别断断续续，可加入外置补光灯。

## 部署使用

与知识库里已有的 [[K230_nncase图像分类部署]] 部署链路同源（同为 nncase kmodel → KPU 推理），但**后处理不同**：

```python
import nncase_runtime as nn
import ulab.numpy as np

kpu = nn.kpu()
kpu.load_kmodel("/sdcard/mp_deployment_source/铁球检测_2026电赛.kmodel")
# ... ai2d 预处理同上 ...
kpu.set_input_tensor(0, ai2d_output_tensor)
kpu.run()
output_data = kpu.get_output_tensor(0)
result = output_data.to_numpy()
# ⚠️ 检测输出是 [num_boxes, 5+num_classes]（x,y,w,h,conf,cls...），
#    需 NMS + 置信度过滤，不是分类的 argmax(softmax)
```

> 具体检测后处理（YOLOv5 解码 + NMS）需按 nncase 版本与输出布局适配，此卡仅记录模型元信息，未附推理脚本。

## 关键点 / 注意事项

1. **任务类型差异**：检测（框）≠ 分类（类别），部署代码不能直接套用扑克牌分类的 softmax 后处理。
2. **光照敏感**：数据含高光点，实际应用建议固定光照 / 加遮光，或补充无高光负样本重训。
3. **类别数**：单类检测，输出通道数为 `5 + 1 = 6`（x/y/w/h/conf/cls），具体以训练导出配置为准（类别名存于训练 yaml，未写入 kmodel 二进制，需回查训练工程确认）。
4. **原件保留**：收件箱 `best.kmodel` 未删除，确认归档无误后可手动清理。
