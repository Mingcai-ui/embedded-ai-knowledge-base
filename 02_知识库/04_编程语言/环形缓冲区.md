# 环形缓冲区（Ring Buffer）

> 一句话：用一段固定数组 + 读写指针，实现「先进先出、写满绕圈」的高效缓冲，是串口 / DMA 接收的核心数据结构。

> 说明：本文为学习要点记录，后续可补上本人工程里的实现代码。

## 1. 原理

- 底层一块固定大小数组 `buf[N]`，两个索引：`head`（写）/ `tail`（读）。
- 写：`buf[head] = data; head = (head + 1) % N;` 读：`data = buf[tail]; tail = (tail + 1) % N;`
- 用 `% N` 绕圈；当 `N` 是 2 的幂时可用 `& (N-1)` 代替取模，更快。

## 2. 判空 / 判满

两种常见写法：

1. **牺牲一个空位（最稳）**：满 = `(head + 1) % N == tail`；空 = `head == tail`。
2. **加计数变量 `count`**：满 = `count == N`；空 = `count == 0`。

## 3. 关键要点

- **单生产者-单消费者**（一个中断写、一个任务读）可**无锁**：写方只动 `head`，读方只动 `tail`，索引用 `volatile` 即可——UART/DMA 场景常用。
- 必须区分「空」和「满」，否则无法判断状态。
- 空间换时间：不做数据搬移，读写 O(1)。

## 4. 最小实现（示例）

```c
#define RB_SIZE 256          // 2 的幂，可用 & 取模
static uint8_t  rb_buf[RB_SIZE];
static volatile uint32_t rb_head, rb_tail;

static inline bool rb_empty(void){ return rb_head == rb_tail; }
static inline bool rb_full(void){ return ((rb_head + 1) & (RB_SIZE - 1)) == rb_tail; }

bool rb_put(uint8_t d){
    if (rb_full()) return false;              // 满则丢弃 / 返回失败
    rb_buf[rb_head] = d;
    rb_head = (rb_head + 1) & (RB_SIZE - 1);
    return true;
}
bool rb_get(uint8_t *d){
    if (rb_empty()) return false;
    *d = rb_buf[rb_tail];
    rb_tail = (rb_tail + 1) & (RB_SIZE - 1);
    return true;
}
```

## 5. 与串口接收配合

- DMA / 空闲中断把整批字节搬进环形缓冲（字节级削峰），再由**消息队列**把「一整帧」交给协议解析任务（包级）——两级缓冲见 [[FreeRTOS_任务管理与消息队列]]。
- 环形缓冲只解决「字节不丢」，帧边界与校验交给上层状态机：[[UART自定义帧协议_接收状态机与防误识别]]。
