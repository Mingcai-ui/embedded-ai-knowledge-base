# PCB设计规则与注意事项

## 简介
- 收集 PCB 画板的通用规则与注意事项，覆盖布局、布线、电源/去耦、EMC、封装散热、出图检查。
- 内容为通用工程经验（trust_level≈L0），具体数值需结合工艺厂与叠层确认，**以 EDA DRC 和制造厂最小工艺为准**。
> 本笔记结构预留「待补充」分区，后续按需补充专属经历/数值；每条可标注来源或验证情况。

## 1. 设计流程与前置准备
- 先做**叠层与阻抗预估**：确定层数（2/4 层）、板厚、铜厚、整板阻抗（USB/差分 90Ω、信号 50Ω）。
- 出网表前先**核对原理图**：电源树、上/下拉、去耦、引脚（对照 [[STM32F103C8T6-芯片资源与PinMux速查]]）。
- 设置 **设计规则**（Clearance/线宽/过孔孔径）再布线，避免后期返工。
- 布线前先规划**电源分配网络**与关键约束网络（时钟、差分、晶振、电源）。

## 2. 布局规则
- **功能分区**：数字区 / 模拟区 / 电源区 / 大电流区分开，接口（USB/串口/电源座）靠板边。
- **关键器件优先**：晶振、开关电源芯片、主控 MCU 先摆，再摆外围。
- 晶振尽量靠近 MCU 引脚，走线短且等长，**晶振下方避免走其他信号线**（减少干扰）。
- 电源输出端靠近电源座/负载端，滤波器前小后大。
- 高频/大功率与敏感信号尽量拉开。

## 3. 布线规则
- **线宽经验**（1oz 铜，常见参考）：信号线 6~10mil；铺铜 12mil 起步；电源按电流加宽。
- **电源线宽电流参考**（1oz 铜，1mm 内层≈1A 量级参考，表层略高），高频/长走线按 2A 以上留裕量。
- **线距**：信号与信号 6mil 起；强弱电/高低压间留足够爬电安全间距。
- **优先短而直**：高频、时钟、敏感线尽量短、少打过孔、避免锐角（用 45° 或圆弧）。
- **时钟/差分等长**：大电流回路上（地）尽量连续，**避免跨越分割地/电源平面**。

## 4. 电源与去耦
- **去耦电容放时钟/电源引脚附近**：0.1µF 靠近每个电源引脚，配合 10~100µF 大电容。
- **开关电源（Buck，如 TPS54627）布局关键**：
  - 输入/输出电容尽量靠近对应引脚，**热回路（高边开关→电感→续流二极管→输入电容）面积要最小化**。
  - 电感、续流二极管靠近开关脚，SW 节点铜箔尽量短；**反馈电阻取样点走远离开关节点处**，避免噪声。
  - 输出纹波与环路稳定相关，AGND/PGND 处理见芯片数据手册（[[TPS54627电源芯片档案]] → 档案）。
- 模拟部分 VDDA/VSSA 单独滤波，必要时用小磁珠/电阻隔离。

## 5. 地平面与回流
- 尽量保证**完整地平面**；分割地时信号不得跨越分割处（否则回流路径被切断）。
- 数字地/模拟地/功率地**单点连接**在合适位置（如电源座附近）。
- 大电流回路走**短粗**，减少寄生电感与压降。

## 6. 焊盘 / 封装 / 散热 / 丝印
- 焊盘孔径与引脚匹配，注意**过孔不要打在焊盘上**（除非盘中孔工艺），避免漏锡。
- 大电流/功率管加散热焊盘 + 过孔阵列散热，适当加开窗。
- 丝印：标注极性、丝印不压焊盘/过孔，方向一致便于目检。

## 7. 出图 / DRC / 制造
- 出图前跑**完整 DRC**（间距、未连接、孤铜、钻孔重叠），并做**3D 预览**核对封装极性、干涉。
- 确认**工艺参数**：板厚、铜厚、最小线宽线距、孔径、表面处理（HASL/沉金）、拼板/工艺边。
- 提交前再次核对**输出文件**（Gerber/钻孔/坐标/BOM），首板注意可测试性（测试点/对插）。

## 8. 常用经验参考（速查）
| 项目 | 参考值/做法 |
|---|---|
| 信号线宽 | 6~10mil |
| 线距 | ≥6mil（信号）；高/低压间按爬电要求加大 |
| 供电线（1oz） | 按电流加宽，预留裕量 |
| 去耦电容 | 0.1µF 就近 + 10~100µF 大电容 |
| 晶振 | 靠近 MCU、下方不走线、等长 |
| 地上分割 | 不跨越分割处走信号 |
