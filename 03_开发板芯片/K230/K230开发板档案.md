## 3. CanMV 关键 API 速记（从 main.py 提炼）

```python
from media.sensor import *      # 摄像头
from media.display import *     # 显示
from media.media import *       # 媒体缓冲管理
import nncase_runtime as nn     # KPU/ai2d 推理
import ulab.numpy as np         # numpy 子集
from machine import UART        # 串口

# UART：UART(设备号, 波特率, tx=引脚, rx=引脚, timeout=ms)
uart = UART(UART.UART2, baudrate=115200, tx=11, rx=12, timeout=10)

# 摄像头双通道：chn0 给显示，chn2 给 AI（不同分辨率/格式可独立设置）
sensor.set_framesize(width=W, height=H)                          # chn0
sensor.set_framesize(width=W2, height=H2, chn=CAM_CHN_ID_2)      # chn2
sensor.set_pixformat(PIXEL_FORMAT_RGB_888_PLANAR, chn=CAM_CHN_ID_2)

# KPU 推理：kmodel 从 SD 卡加载，ai2d 做 resize 预处理
kpu = nn.kpu(); kpu.load_kmodel("/sdcard/mp_deployment_source/xxx.kmodel")
kpu.set_input_tensor(0, tensor); kpu.run(); out = kpu.get_output_tensor(0)
```

## 4. 部署文件约定（Aidex/CanMV 训练部署流程）

- 模型与配置放 `/sdcard/mp_deployment_source/`
- `deploy_config.json` 字段：`kmodel_path`、`categories`（标签列表）、`confidence_threshold`、`img_size`、`num_classes`
- 标签格式（本项目）：`10A/10B/10C/10D`（10+花色）、`2A~AD`（点数+花色）、`KingA/KingB`（大小王）、`AA/AB`（未识别）

## 5. 已知限制与注意事项（项目经验）

- **发送限流**：识别结果不能每帧都发 UART，需加最小发送间隔（本项目 200ms），否则淹没 STM32 接收。
- **内存管理**：主循环内每帧 `gc.collect()`；异常退出路径必须依次释放 sensor/Display/MediaManager 并 `nn.shrink_memory_pool()`。
- **非阻塞写入**：UART 写入注意 TX FIFO 状态，避免阻塞视觉主循环。
