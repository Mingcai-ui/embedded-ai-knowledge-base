# TPS54627｜芯片资源与引脚速查

> 适用边界：TPS54627，DDA（HSOP8）封装，6A 同步降压转换器。
> 本文档基于 TI 官方数据手册（ZHCSBN2A，2013-09）蒸馏，**不等于实物上板验证**。

## 1. 芯片身份与核心规格

| 项 | 值 |
|---|---|
| 类型 | 6A 同步降压（buck）DC-DC 转换器 |
| 控制模式 | D-CAP2™（自适应导通时间） |
| 集成 MOSFET | 2× N 沟道（高侧 36mΩ / 低侧 28mΩ） |
| 输入电压 | 4.5V ~ 18V |
| 输出电压 | 0.76V ~ 5.5V |
| 开关频率 | 650kHz（伪恒定） |
| 封装 | DDA（HSOP8，8 脚 + 散热焊盘） |
| 工作温度 | -40°C ~ 85°C（结温 -40°C ~ 150°C） |

## 2. 引脚功能详解

| 引脚号 | 名称 | 类型 | 功能描述 |
|---|---|---|---|
| 1 | EN | 输入 | 使能输入，高有效，需上拉使能器件 |
| 2 | VFB | 输入 | 转换器反馈输入，接输出分压电阻 |
| 3 | VREG5 | 输出 | 5.5V 电源输出，典型接 1µF 电容到 GND；EN 低时无效 |
| 4 | SS | 输入 | 软启动控制，外部电容到 GND |
| 5 | GND | 地 | 开关电路功率地回流通路，SS/VFB 返回需单点接地 |
| 6 | SW | 输出 | 开关节点，高侧与低侧 NFET 之间 |
| 7 | VBST | 输入 | 高侧 FET 栅极驱动电源，接 0.1µF 到 SW；内部 VREG5-VBST 有二极管 |
| 8 | VIN | 输入 | 输入电源引脚 |
| 背板 | Thermal Pad | 散热 | **必须焊接到 GND** 以保证散热 |

## 6. 保护功能汇总

| 保护 | 机制 | 是否锁存 |
|---|---|---|
| 过流保护 OCP | 逐周期谷值检测，7 个连续过流周期后降 OCL 阈值 | 非锁存 |
| 过压保护 OVP | VFB > 125% 目标电压时关断上下管 | 非锁存 |
| 欠压保护 UVP | VFB < 65% 目标电压，持续 250µs 后关断进入打嗝 | 非锁存 |
| UVLO | VREG5 低于阈值时关断 | 非锁存 |
| 热关断 TSD | 结温 > 165°C 关断，迟滞 35°C | 非锁存 |

## 9. 待确认与冲突

- [待确认] PDF 提取产物中「推荐工作条件-输出电流范围 I_O」一行数值缺失，仅能确认 6A 为额定上限（来源：特征描述）。如需精确 I_O 上下限，需查阅原 PDF 该行或联系 TI。
- [待确认] 手册无独立时钟振荡器说明，650kHz 为"伪恒定频率"，实际频率随 VIN/VO 微调，非精确固定值。
- [冲突待处理] 无（本手册为唯一来源）。
