# TPS54627 电源芯片档案

> 适用边界：TPS54627，DDA（HSOP8）封装，6A 同步降压（buck）DC-DC 转换器。
> 本文档基于 TI 官方数据手册（ZHCSBN2A，2013-09 修订）蒸馏，**不等于实物上板验证**。
> 状态分级：所有电气参数默认「手册已确认」（L0），未上板验证项一律标「待确认」。

## 1. 芯片身份与资料入口

| 项 | 值 |
|---|---|
| 芯片型号 | TPS54627 |
| 类型 | 6A 同步降压（buck）转换器，内置两个 N 沟道 MOSFET |
| 控制方式 | D-CAP2™ 自适应导通时间（伪恒定频率 650kHz） |
| 封装 | DDA（HSOP8，8 引脚 + Exposed Thermal Pad） |
| 厂商 | Texas Instruments (TI) |
| 数据手册版本 | ZHCSBN2A（2013 年 4 月首发，2013 年 9 月修订） |
| 手册路径 | `00_收件箱/TPS54627DDAR手册.pdf` |
| 官网 | www.ti.com.cn |

**关键一句话**：TPS54627 是 4.5V~18V 输入、0.76V~5.5V 输出、最高 6A 的同步降压电源芯片，用 D-CAP2™ 控制实现快速瞬态响应，无需外部补偿，适合低电压数字系统（数字电视、蓝光播放器、网络终端、机顶盒等）供电。

## 3. 引脚功能速查

| 引脚号 | 名称 | 功能 |
|---|---|---|
| 1 | EN | 使能输入，高有效，需上拉使能 |
| 2 | VFB | 反馈输入，接输出电压电阻分压器 |
| 3 | VREG5 | 5.5V 电源输出（EN 低时无效），需 1µF 电容到 GND |
| 4 | SS | 软启动控制，外部电容到 GND |
| 5 | GND | 地（功率地回流通路） |
| 6 | SW | 开关节点（高/低侧 NFET 之间） |
| 7 | VBST | 高侧 FET 栅极驱动电源输入，接 0.1µF 电容到 SW |
| 8 | VIN | 输入电源 |
| 背板 | Thermal Pad | 散热焊盘，**必须焊接到 GND（PGND）** |

## 4. 典型应用与设计要点

- **输出电压设定**：`VOUT = 0.765 × (1 + R1/R2)`，R2 固定 22.1kΩ。
- **软启动时间**：`tSS(ms) = C6(nF) × 0.765 × 1.1 / 6`，SS 充电电流 6μA。
- **输出滤波**：LC 双极点 `Fp = 1/(2π√(L×C))`，电感/电容选型见 Table 1（详见速查档案）。
- **Bootstrap 电容**：VBST-SW 之间必须接 0.1µF 陶瓷电容。
- **VREG5 电容**：VREG5-GND 之间必须接 1µF 陶瓷电容。
- **输入电容**：≥10µF 去耦，另加 0.1µF（C3）可选高频滤波。
- **热设计**：散热焊盘必须焊接到 PCB 地铜平面，通过热过孔导到内层地平面。

## 5. 已知限制与注意事项

- 输出电流峰值受 OCL 限制（6.7~8.9A），实际持续输出以 6A 为上限。
- 输出电压超过 1.8V 时建议加前馈电容 C4（并联 R1）提升相位裕度。
- 电感饱和电流必须大于峰值电流（设计示例峰值 6.51A）。
- 散热焊盘不焊接会导致散热不足，器件可能热关断。
