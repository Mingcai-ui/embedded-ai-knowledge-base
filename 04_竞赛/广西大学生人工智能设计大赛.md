# 广西大学生人工智能设计大赛

## 简介

广西大学生人工智能设计大赛是由自治区教育厅主办的省级学科竞赛，面向广西区内及区外受邀的全日制在校高职、专科、本科生和研究生。目的是普及智能科学与技术知识，提高学生采用智能科学技术解决实际问题的能力，培养创新意识与团队合作精神。

> 本笔记依据 2024 年（第六届）与 2025 年（第七届）两份官方公告整理。

## 大赛基本信息

| 项目 | 内容 |
| --- | --- |
| 主办 | 自治区教育厅 |
| 指导 | 自治区工业和信息化厅、自治区科学技术协会 |
| 协办 | 广西本科高校计算机类专业教学指导委员会、广西人工智能学会 |
| 承办 | 桂林电子科技大学等高校 |
| 参赛对象 | 全日制在校高职、专科、本科生、研究生（区外邀请赛亦可） |
| 组队 | 每队 ≤3 人，设 1 名组长、1~2 名指导老师；不得跨校组队 |
| 费用 | 不收参赛费，交通住宿由学校负责 |
| 官方渠道 | 广西本科教育网 http://bkjy.gxeduyun.edu.cn/ |

## 选题方向（赛道）

比赛分**自主选题**和**指定选题**两种方式。

- **自主选题**：开放式，题目须围绕人工智能，可软可硬，体现智能性、创新性、实用性。推荐虚拟现实（VR/AR/MR/XR/AI）方向。
- **指定选题**（2025 年）：
  | 赛道 | 举办地点 | 方向 |
  | --- | --- | --- |
  | 四足多模态巡检 | 柳州城市职业学院 | 宇树科技四足机器人自主巡检 |
  | 物联网设计应用技能竞赛 | 河池学院 | 物联网数据采集 + 网络传输 + 应用软件 |
  | 自主命题 | 桂林电子科技大学 | 自由选题 |

下面重点整理**物联网设计应用技能竞赛**（本知识库关联方向）。

## 重点赛道：物联网设计应用技能竞赛

### 决赛技术层次（官方给出的四个选项）

官方将决赛内容划分为四个技术层次，对应一套完整的「感知 → 控制 → 传输 → 应用」物联网链路：

| 层次     | 考察内容                                                         |
| ------ | ------------------------------------------------------------ |
| ① 感知层  | 温湿度、光照度、RFID、可燃气体等传感器的驱动；单片机、嵌入式 Linux 数据采集设备                |
| ② 设备控制 | 风扇、电机、声光报警器、继电器等被控设备                                         |
| ③ 网络层  | ZigBee、Wi-Fi、LoRaWAN、NB-IoT、4G 等网络通信程序设计；MQTT 协议；采集数据上传、设备控制 |
| ④ 应用层  | 以智慧农业为背景设计应用软件，语言不限（Java Web、Android、微信小程序、C#、Python 等）      |

### 网络层 vs 应用层：选一种主攻开发

决赛得分由两大单元构成，分别对应上面的四个层次：

- **嵌入式单元（= 感知层 + 设备控制 + 网络层）**，总分 50 分
- **应用软件开发单元（= 应用层）**，总分 50 分

因此备赛时队伍可根据自身专长，在**网络层（嵌入式方向）**和**应用层（软件方向）**中**选择一种作为主攻开发方向**，最终以完成任务累加的分数计总分（满分 100 分）。

### 赛制与评分

- **初赛**：各高校自行组织，学校专家评审，考察作品创意、技术路线可实现性、应用价值。
- **决赛**：现场技能赛，时长 4 小时。任务书含嵌入式单元 + 应用软件开发单元，每题若干任务，按分数累加计分。**目前规则已更新：选手可以使用自己的电脑（但现场不能联网）**。

## 比赛时要做的（概括）

以 2024 年任务书为例，决赛共两道题：

1. **农业物联网系统（70 分）**：智能节点采集温湿度、光照度、两路旋钮电压并显示 → 手动/自动模式控制风扇（配合指示灯/蜂鸣器）→ LoRa 传到 4G 节点、4G 上传到 MQTT 云端 → web 端实时显示 + 登录 + 手动/自动控制。
2. **基于物联网的图书管理系统（30 分）**：RFID 刷卡采集借阅者 ID → WiFi → 4G 节点 → 4G → MQTT → web 端列表显示借阅记录；云端控制蜂鸣器实现火灾报警疏散。

> 现场实操注意：WiFi 热点名、ZigBee/LoRa 网络 ID、MQTT Topic 均须按「赛场号 + 座位号」命名，避免队伍间互相干扰（如 `WIFI_1_1`、`4G_team_1_1`）。

## 备赛要求

**技能要求**
- 单片机/嵌入式 Linux 数据采集：驱动温湿度、光照度、RFID、旋钮电压等传感器
- 外设控制与状态显示：按键、LED 指示灯、蜂鸣器、显示屏（手自动模式切换逻辑）
- 通信协议与网络：LoRa、WiFi、ZigBee、NB-IoT、4G 其中至少一种 + MQTT 协议
- 应用软件开发：web（登录、实时显示、远程控制）或 Android 端，语言不限
- 熟悉赛场时间节奏：4 小时现场限时完成任务书

**硬件准备**
- 单片机 / 嵌入式 Linux 智能节点（融合 ZigBee、WiFi、LoRaWAN、NB-IoT、4G）
- 传感器（温湿度、光照、可燃气体、北斗模组等）+ 被控设备（风扇、电机、声光报警器、继电器、可调灯）
- RFID、语音识别模块、网关

**软件工具**
- MDK5 / KEIL MDK / IAR（下位机开发）
- Visual Studio 2012、Android Studio（上位机/App 开发）
- SQL Server 2008 数据库、串口/网络调试助手

**团队与规则**
- 每人限报 1 队，不得跨校组队；指导老师须本校在职/兼职
- 硬件制作、软件编程、系统调试、报告须由学生独立完成
- 现场可使用自己的电脑，但**不能联网**（预装好依赖、备好离线资料）
- 比赛前可提前准备各传感器、外设控制器的**模块代码**，并提前在自己电脑上**配置好所需开发环境**

**离线准备建议（现场不能联网）**
- **依赖与库**：提前下载并缓存开发所需依赖——MDK/HAL 库包、Arduino 库、Python 包、模型/onnx/nncase 工具链等，确保断网也能编译部署
- **文档与示例**：本地备好数据手册、寄存器手册、通信协议文档、示例工程、调试工具离线安装包
- **模块代码**：各传感器（温湿度、光照、RFID、旋钮 ADC 等）与外设控制器（风扇、电机、继电器、LED、蜂鸣器、按键）的驱动代码提前写好并验证，整理成可复用工程模板
- **开发环境**：赛前在自己电脑上完整配好 IDE、交叉编译/烧录工具链、串口/网络调试助手、虚拟机或 Docker（如需 Linux），现场直接可用
- **联网替代**：排查代码里依赖联网的环节（如远程 MQTT 服务器、云编译、在线拉取），改用本地服务或离线方案，提前打通数据链路
- **本地检索**：把关键引脚映射、协议命令、初始化/轮询示例等整理成本地可查的笔记，赛前理清接线与调用顺序
