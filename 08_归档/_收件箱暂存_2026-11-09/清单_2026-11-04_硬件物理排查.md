# 硬件物理排查（供电→晶振→复位→IO）

> 定位：软件改不动时，"是不是压根不是软件问题"的体检顺序。
> 我硬件基础不错（看得懂原理图、焊接、电源、上下拉，见 [[个人画像]] 3.2），但**缺仪器使用记录**（画像短板 #8：无示波器/逻辑分析仪）。本篇补齐"从万用表到逻辑分析仪"的完整排查链。

---

## 0. 一条总原则

**软硬件问题先分界，再从"最底层的电"往上查。**

顺序永远固定：**供电 → 晶振/时钟 → 复位 → 引脚/外设 → 信号质量**。
跳过底层直接查信号，99% 会绕远路（类似 [[K230容器_RemoteSSH连不上_sshd未启动]]：该先验服务端，结果去查客户端配置）。

---

## 1. 分界：这到底是软件还是硬件？

| 判断动作 | 结论 |
|---|---|
| 换一块板子，同一固件，现象一样 | 软件问题（或固件里某个板级假设错了） |
| 同一块板，换回"确定能跑"的老固件，现象消失 | 软件回归（新代码引入） |
| 同一固件，换板子现象变化/消失 | 硬件问题（这块板子） |
| 用手按一按芯片/晶振/接头，现象抖动 | 虚焊 / 接触不良 |

> 分界这一步最省时间，先做。

---

## 2. 万用表排查顺序（第一把刀，最常用）

### 2.1 供电（最先查）

| 量什么 | 红笔 | 黑笔 | 期望 |
|---|---|---|---|
| 3.3V 电源轨 | VDD 引脚/3.3V 测试点 | GND | 3.3V ±5%（3.14~3.46） |
| 5V（若有） | 5V 测试点 | GND | 4.75~5.25 |
| LDO/降压芯片输出 | 输出引脚 | GND | 标称值 |
| 电源纹波（初步） | — | — | 用示波器 AC 档看（§5） |

**先测总电源，再测每个芯片的 VDD 引脚**（有些芯片供电和主电源轨之间还有独立 LDO/开关）。

### 2.2 通断（查断线/短路）

- 蜂鸣档量"该通不通"（断线、虚焊、排线断了）。
- 量"不该通却通"（短路、锡桥，见 [[PCB锡桥_相邻焊盘连通短路]]）。
- **短路排查技巧**：板子不上电，量 VDD 对 GND 的阻值——正常几十 kΩ 到几百 kΩ；若接近 0，说明有短路，用"分段断开法"定位到是哪个器件。

### 2.3 电压逻辑电平（查 IO）

- 量 GPIO 输出高低电平：高应接近 VDD，低应接近 0V。
- 量通信引脚空闲电平：UART 空闲应为高，I2C 上拉后空闲为高，SPI 看极性。
- 量"该高不高 / 该低不低" → 上拉/下拉电阻缺失、方向配置错、引脚冲突。

### 2.4 电流（查异常功耗）

- 串入万用表电流档，量整机静态电流。
- 正常待机几 mA~几十 mA；异常大（几百 mA）→ 短路或某外设常开；异常小或为 0 → 没上电/断路。

## 3. 时钟与复位（第二、三步，容易被忽略）

### 3.1 晶振不起振

- **现象**：串口没输出、程序卡在启动，或所有定时外设全废（UART 波特率错乱、LED 定时不闪）。
- **排查**：
  1. 示波器量晶振两脚（X1/X2），正常有正弦波（8MHz 或 32.768kHz 看板子）。
  2. 没有波形 → 查负载电容是否匹配、晶振是否虚焊、旁路电容。
  3. 波形异常（幅度太小/畸变）→ 负载电容值不对。
- **速判**：CubeMX 里若误把 HSE 配成 HSI，或晶振没接但代码用了 HSE，现象就是"整个系统时钟错了"。

### 3.2 复位异常

- **现象**：芯片反复重启 / 上电无反应 / 运行中随机复位。
- **排查**：
  1. 量 NRST 引脚电平（正常高，按下复位键变低再回高）。
  2. 上电瞬间 NRST 有没有正常拉低再释放（复位电路 R+C 是否对）。
  3. 看门狗误触发：软件喂狗太晚 → 先确认是不是 IWDG/WWDG 配置问题（这是软件，但表现像硬件重启）。

## 4. 逻辑分析仪（查通信时序的利器）

> 采购清单里已列 ¥30 逻辑分析仪，正是补这块短板（[[采购清单]]）。

### 4.1 能解决什么

- UART / I2C / SPI / RS485 / 单总线 的**波形对不对、时序对不对**。
- "数据到底发出去了没""波特率对不对""有没有被干扰打断"——这些肉眼和 printf 都看不到。

### 4.2 用法

1. 夹子接 GND + 你要看的信号线（TX/RX/SCL/SDA/DE/RE 等）。
2. 设采样率（≥ 波特率的 10 倍；UART 115200 建议 2MHz 以上）。
3. 触发后看波形，软件自带协议解码（UART 直接解出 ASCII/HEX）。

### 4.3 常见结论

| 看到的现象 | 结论 |
|---|---|
| 波形规整、数据正确 | 链路没问题，问题在软件解析 |
| 有波形但电平不对（3.3V 系统看到 5V 或 1.8V） | 电平不匹配，缺电平转换 |
| 波形畸变/毛刺/振铃 | 线路过长、缺终端电阻、地线不好 |
| 完全没有波形 | 没发出来，查软件发送/方向切换（RS485 的 DE/RE） |
| 波特率对不上（位宽≠1/115200） | 时钟配置错（回到 §3.1） |

### 4.4 RS485 特有：方向切换时序

- 半双工 RS485 靠 DE/RE 切方向，**切换和发数据之间要有延时**，否则会丢开头几个字节或发不出去。
- 逻辑分析仪抓 DE + TX 两路，看"DE 拉高 → 数据上线"之间的间隔。

## 5. 示波器（查信号质量与电源，进阶）

### 5.1 什么时候必须用（万用表搞不定的）

- 信号**边缘/振铃/过冲**：高速信号、长线传输。
- **电源纹波**：用 AC 耦合档，看 3.3V 上有没有毛刺（数字电路偶发错误常源于电源噪声）。
- **时序精确测量**：脉宽、周期、相位差。
- **上电时序**：多路电源谁先谁后。

### 5.2 基础操作要点

- 探针 1×/10× 选对，10× 记得补衰减补偿。
- 测纹波用 AC 耦合 + 带宽限制 20MHz + 探针就近接地（长地线夹会引入假纹波）。
- 触发电平设对，否则抓不到。

### 5.3 典型排查

| 症状 | 示波器看什么 |
|---|---|
| 偶发通信错误 | 电源纹波、信号毛刺 |
| 电机/继电器动作时 MCU 复位 | 3.3V 在负载切换瞬间的跌落（brown-out） |
| I2C 偶尔读错 | SCL/SDA 边沿是否干净、上拉是否够 |

## 6. 焊接与装配（动手排查）

- **虚焊**：烙铁加一点助焊剂，逐个焊点重新烫一遍（最省力的"重新焊接"）。
- **锡桥/短路**：放大镜或手机微距看焊盘间距，见 [[PCB锡桥_相邻焊盘连通短路]]。
- **冷焊/氧化**：焊点发灰不亮，加助焊剂重焊。
- **接插件接触不良**：拔插几次、量通断。
- **静电**：干燥环境手摸芯片前先放静电；已损坏的芯片现象往往诡异且不稳定。

## 7. 物理排查清单（软件走不动时逐条过）

```
□ 1. 分界：换板/换固件，判断软还是硬（§1）
□ 2. 供电：总电源 → 每芯片 VDD，量电压（§2.1）
□ 3. 短路：VDD 对 GND 阻值（§2.2）
□ 4. 时钟：晶振起振没（示波器）（§3.1）
□ 5. 复位：NRST 电平、看门狗（§3.2）
□ 6. 引脚：IO 电平、上拉下拉、方向（§2.3）
□ 7. 通信：逻辑分析仪抓波形（§4）
□ 8. 信号质量：示波器纹波/毛刺（§5）
□ 9. 焊接：虚焊/锡桥/接触不良（§6）
```
