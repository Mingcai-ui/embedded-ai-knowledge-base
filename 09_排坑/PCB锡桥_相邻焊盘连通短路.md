# PCB 相邻焊盘上锡后连通短路

## 环境
- 芯片 / 板卡：自制 PCB / 打样板
- 工具链 / 版本：烙铁手工上锡

## 现象
- PCB 上两个相邻的锡皮（焊盘）在上锡后被连成一块，引脚之间短路。

## 原因
- 出现锡桥（solder bridge）：相邻焊盘间距过小，或上锡量过多，多余锡料在焊盘之间连成一条桥。

## 解决
- 减少上锡量；上锡后用烙铁 + 助焊剂沿焊盘间隙拖锡，把多余锡带开。
- 间距过密的焊盘改用贴片回流焊 / 钢网，避免手工堆锡。
- 设计阶段用 DRC 检查焊盘间距，留足爬锡间隙。
