# PID 灰度循迹黑线处电机全速 / 无法反转

## 环境
- 芯片 / 板卡：PID 电机灰度循迹小车（STM32 等）
- 工具链 / 版本：-

## 现象
- 灰度某一路检测到黑线后，电机全速运转；或无法反转，只能差速行驶。

## 原因
- 速度变量定义成无符号类型（uint8 / uint16 / uint32），无法表示负值。需要反转时，负值被回绕成最大值，导致电机按最大速度（全速）运转。

## 解决
- 速度 / PID 输出变量改为有符号类型（int8_t / int16_t / int32_t）。
- PWM 输出前把有符号速度映射为正负方向 + 占空比，避免直接写入无符号寄存器时发生回绕。
