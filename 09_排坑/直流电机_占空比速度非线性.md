# 直流电机不能线性加速（占空比与速度非线性）

## 环境
- 芯片 / 板卡：直流电机 + PWM 驱动（STM32 定时器输出 PWM，循迹小车项目）
- 工具链 / 版本：-

## 现象
- 期望占空比线性增加时电机转速线性上升，实际却不是：
  - 占空比从 0 加到某个值，电机完全不动（卡在死区）。
  - 超过死区后电机突然起转，转速直接跳变，低速段无法精细控制。
  - 高速段再加占空比，转速变化趋于饱和，加速曲线整体呈"S"形而非直线。

## 原因
- **电机存在死区电压（启动电压）**：低于死区占空比时，电枢平均电压不足以克服静摩擦力矩和电刷压降，电机不转。
- **占空比与转速天然非线性**：直流电机稳态转速由 `n = (U_avg - I·Ra) / Ce·Φ` 决定，平均电压、电枢电阻压降、负载共同作用，空载/重载曲线不同。
- **开环控制无反馈修正**：只开环写占空比，电池电压下降、负载波动都会让同一占空比对应不同转速。
- **PWM 频率不合适**（次要）：频率过低时电枢电流断续，低速力矩波动大、转动不连贯。

## 解决
- **标定死区并做线性映射补偿**（开环方案）：
  1. 实测电机起转的最小占空比 `D_dead`（如 20%）和最大有效占空比 `D_max`（如 100%）。
  2. 把期望的 0~100% 线性速度值映射到 `[D_dead, D_max]` 区间：

  ```c
  // duty: 期望线性速度 0~100；实际输出占空比考虑死区补偿
  #define D_DEAD   20   // 实测死区占空比
  #define D_MAX    100
  int16_t Motor_MapSpeed(int16_t speed)   // speed: 0~100
  {
      if (speed == 0) return 0;           // 0 直接停车
      return D_DEAD + (int16_t)((int32_t)speed * (D_MAX - D_DEAD) / 100);
  }
  ```
- **改闭环控制**（根治方案）：加编码器测速，用 PID 速度环直接控制转速，占空比只是 PID 输出，自动抵消死区和电源波动（可配合前馈：PID 输出 + 死区基础值）。
- **软启动斜坡**：加速时不要让占空比阶跃，按固定步长逐周期递增，避免电流冲击和转速跳变。
- **PWM 频率选 10~20kHz**：高于人耳听觉上限避免啸叫，同时保证电流连续、力矩平稳。
